# Loblaw Long-Term Debt Dashboard

## Project Overview

This project examines Loblaw Companies Limited's
reported long-term debt in Q1 and Q2 of 2025
compared with Q1 and Q2 of 2026.

The purpose is to identify changes in reported
debt, investigate potential explanations, and
provide financial management recommendations.

## Dashboard Features

- Interactive debt comparison chart
- Historical debt trend chart
- Year-over-year percentage change chart
- Financial findings and recommendations
- Limitations and methodology
- Downloadable CSV dataset

## Technologies

- HTML
- CSS
- JavaScript
- Chart.js
- GitHub Pages

## Repository Contents

- index.html: Dashboard
- data.csv: Financial dataset
- README.md: Project documentation
- sources-and-methodology.md: Data sources
  and research methods

## Data

Source: Loblaw Companies Limited quarterly
financial reports.

Period: Q1 and Q2, 2025 and 2026.

Sample size: Four observations.

Currency: CAD millions.

## How to View

Visit the published GitHub Pages website.

The CSV dataset and research methodology
are available in this repository.

## Limitations

This project uses a small sample and does
not establish causation between operating
performance and reported debt changes.
