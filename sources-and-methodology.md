# Sources and Methodology

## Project
Loblaw Companies Limited: Long-Term Debt
Comparative Analysis, Q1 and Q2 2025–2026.

## Dataset description

Company: Loblaw Companies Limited
Variable: Reported non-current long-term debt
Period: Q1 and Q2, 2025 and 2026
Unit: Millions of Canadian dollars
Sample size: Four quarter-end observations
Data type: Public financial statement data

## Data preparation

- Check each observation against the original
  financial statements.
- Standardize monetary values to CAD millions.
- Check for duplicate year-quarter records.
- Check for missing values.
- Retain actual reporting dates.
- Do not replace missing data with zero.
- Document any changes in debt classification.
- Exclude lease liabilities from the main variable
  unless explicitly studying total debt obligations.

## Statistical methods

Percentage change:

((2026 balance - 2025 balance) /
 2025 balance) * 100

Descriptive statistics:
- Mean
- Median
- Minimum
- Maximum
- Range

## Visualization methods

1. Grouped bar chart:
   Compares 2025 and 2026 balances.

2. Line chart:
   Displays the four selected reporting dates.

3. Percentage change chart:
   Shows year-over-year differences.

## Interpretation

A lower reported non-current long-term debt
balance does not necessarily indicate an actual
cash repayment.

The classification of PC Financial liabilities
as held for sale must be considered when
comparing the financial statements.

## Limitations

- Only four observations.
- Limited historical coverage.
- Accounting classification differences.
- No proof of causation.
- Quarter-end balances do not capture all
  intra-quarter financing movements.

## Data status

The dataset contains public financial data,
not synthetic observations. The four values
must be reconciled to the original report
line items before final publication.
